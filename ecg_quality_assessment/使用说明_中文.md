## 🎯 立即开始使用

### 第1步：测试环境（2分钟）

```bash

python test_installation.py
```

这会检查：
- ✓ 所有依赖包是否已安装
- ✓ TensorFlow是否正常工作
- ✓ GPU是否可用
- ✓ 项目结构是否完整
- ✓ 模块是否能正常导入

### 第2步：查看数据状态

我看到您已经下载了部分数据：
- ✅ MIT-BIH (mitdb) - 训练数据
- ✅ NSTDB (nstdb) - 噪声数据
- ✅ INCART (incartdb) - 测试数据
- ✅ PTB (ptbdb) - 训练数据

如需下载更多数据：
```bash
python download_datasets.py --mode all
```

### 第3步：准备训练数据（10-20分钟）

```bash
python prepare_data.py
```

这会：
1. 从已下载的数据库中提取ECG信号
2. 预处理（重采样、滤波、归一化）
3. 分割成5秒片段
4. 生成含噪信号
5. 数据增强
6. 保存到 `data/processed/` 目录

### 第4步：训练模型（30分钟-2小时）

```bash
python train.py
```

训练配置：
- 批大小：10
- 训练轮数：100
- 学习率：0.001
- 自动保存最佳模型

预计时间：
- GPU (RTX 3080): 约30-45分钟
- GPU (GTX 1080): 约1-1.5小时
- CPU: 约3-5小时

### 第5步：评估模型（5-10分钟）

```bash
# 找到训练好的模型文件（在models/目录）
```

### Python代码示例

创建一个测试脚本 `my_test.py`：

```python
from main import ECGQualityAssessment
import numpy as np
import wfdb

# 1. 加载训练好的模型
model_path = 'models/ecg_quality_model_20260103_145230.h5'
system = ECGQualityAssessment(model_path)

# 2. 加载ECG信号
# 方式A：从WFDB格式加载
record = wfdb.rdrecord('data/raw/mitdb/100')
ecg_signal = record.p_signal[:, 0]  # 取第一个导联
sampling_rate = record.fs

# 方式B：从文本文件加载
# ecg_signal = np.loadtxt('your_signal.txt')
# sampling_rate = 360

# 3. 评估信号质量
quality, confidence = system.assess_signal(ecg_signal, sampling_rate)
print(f"信号质量: {quality}")
print(f"置信度: {confidence:.2%}")

# 4. 评估多个片段
results = system.assess_signal_segments(ecg_signal, sampling_rate)
print(f"\n共找到 {len(results)} 个片段:")
for r in results[:5]:  # 显示前5个
    print(f"  片段 {r['segment_index']}: {r['quality']} "
          f"(置信度: {r['confidence']:.2%})")
```

运行：
```bash
python my_test.py
```

### 场景3：实际应用部署

```python
# 创建简单的API服务
from flask import Flask, request, jsonify
from main import ECGQualityAssessment
import numpy as np

app = Flask(__name__)
system = ECGQualityAssessment('models/best_model.h5')

@app.route('/assess', methods=['POST'])
def assess_ecg():
    data = request.json
    signal = np.array(data['signal'])
    fs = data['sampling_rate']
    
    quality, confidence = system.assess_signal(signal, fs)
    
    return jsonify({
        'quality': quality,
        'confidence': float(confidence)
    })

if __name__ == '__main__':
    app.run(port=5000)
```

## 🐛 故障排除

### 问题：内存不足

**解决方案**：
```python
# 编辑 prepare_data.py
max_segments = 1000  # 减少到1000或更少（原来是5000）

# 或编辑 config.py
TRAINING_CONFIG['batch_size'] = 5  # 减小批大小
```

### 问题：训练太慢

**解决方案**：
1. 确认GPU可用：`python -c "import tensorflow as tf; print(tf.config.list_physical_devices('GPU'))"`
2. 减少训练轮数：编辑 `config.py` 中的 `epochs`
3. 减少训练数据：编辑 `prepare_data.py` 中的 `max_segments`

### 问题：模型性能不佳

**尝试**：
1. 增加训练数据量
2. 调整学习率
3. 增加训练轮数
4. 调整模型架构（在 `config.py` 中）

### 问题：找不到数据文件

**检查**：
```bash
# 查看数据目录
ls data/raw/mitdb/
ls data/raw/nstdb/

# 如果路径不对，编辑config.py中的DATA_PATHS
```
