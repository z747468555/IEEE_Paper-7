## 🚀 如何使用

### 重新生成所有图表

只需重新运行评估脚本：

```bash
# 评估测试集
python evaluate.py --model models/ecg_quality_model_XXXXXX.h5 --test_data processed_data/test_data.npz --dataset_name "Test Set"

# 评估Challenge 2011
python evaluate.py --model models/ecg_quality_model_XXXXXX.h5 --test_data processed_data/pccc2011_test_data.npz --dataset_name "Challenge 2011"

# 评估INCART
python evaluate.py --model models/ecg_quality_model_XXXXXX.h5 --test_data processed_data/incart_test_data.npz --dataset_name "INCART"
```

**输出文件**（在 `results/evaluation_XXXXXX/` 目录）:
- `confusion_matrix_Test_Set.png`
- `roc_curve_Test_Set.png`
- `classification_report_Test_Set.txt`

## 📝 数据集名称建议

### 标准英文名称

| 中文名称 | 推荐英文名称 | 说明 |
|---------|-------------|------|
| 测试集 | `Test Set` | 来自训练数据库的测试集 |
| Challenge 2011 | `Challenge 2011` 或 `PhysioNet 2011` | PhysioNet挑战赛数据 |
| INCART | `INCART` 或 `St. Petersburg INCART` | INCART数据库 |
| 训练集 | `Training Set` | 训练数据 |
| 验证集 | `Validation Set` | 验证数据 |

### 使用示例

```bash
# 方式1：使用引号
python evaluate.py --model MODEL.h5 --test_data DATA.npz --dataset_name "Test Set"

# 方式2：使用下划线（如果不想用引号）
python evaluate.py --model MODEL.h5 --test_data DATA.npz --dataset_name Test_Set
```
