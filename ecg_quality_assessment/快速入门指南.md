# ECG信号质量评估系统 - 快速入门指南

本指南将帮助您快速上手ECG信号质量评估系统，复现论文实验。

## 📋 前置要求

- Python 3.7+
- CUDA（可选，用于GPU加速）
- 至少10GB可用磁盘空间（用于存储数据集）
- 稳定的网络连接（用于下载数据集）

## 🎯 5步快速开始

### 第1步：安装依赖（约2分钟）

```bash
cd ecg_quality_assessment
pip install -r requirements.txt
```

安装的主要包：
- `tensorflow`: 深度学习框架
- `wfdb`: PhysioNet数据库访问工具
- `scipy`: 信号处理
- `numpy`, `pandas`: 数据处理
- `matplotlib`, `seaborn`: 可视化

### 第2步：下载数据集（约30-60分钟）

**选项A：快速测试模式（推荐初学者）**
```bash
python download_datasets.py --mode essential
```
- 仅下载必需的数据集
- 下载时间：约10-15分钟
- 磁盘空间：约2-3GB

**选项B：完整复现模式**
```bash
python download_datasets.py --mode all
```
- 下载所有数据集
- 下载时间：约30-60分钟
- 磁盘空间：约8-10GB

**选项C：手动下载**
如果自动下载失败，可以手动从PhysioNet下载：
1. 访问 https://physionet.org/
2. 下载以下数据集：
   - MIT-BIH Arrhythmia Database (mitdb)
   - PTB Diagnostic ECG Database (ptbdb)
   - MIT-BIH Noise Stress Test Database (nstdb)
   - St Petersburg INCART 12-lead Arrhythmia Database (incartdb)
   - PhysioNet/Computing in Cardiology Challenge 2011 (challenge-2011)
3. 解压到 `data/` 目录对应位置

### 第3步：准备训练数据（约10-20分钟）

```bash
python prepare_data.py
```

这一步会执行：
1. 加载原始ECG信号
2. 预处理（重采样、滤波、归一化）
3. 分割成5秒片段
4. 生成含噪信号
5. 数据增强
6. 划分训练集和测试集

输出文件（保存在 `processed_data/` 目录）：
- `training_data.npz`: 训练数据
- `test_data.npz`: 测试数据（来自训练数据库）
- `incart_test_data.npz`: INCART测试数据（未见数据）
- `pccc2011_test_data.npz`: Challenge 2011测试数据（未见数据）

### 第4步：训练模型（约1-2小时）

```bash
python train.py
```

训练过程会：
- 自动使用GPU（如果可用）
- 显示训练进度
- 保存最佳模型
- 生成训练曲线图
- 记录训练日志

训练时间估计：
- GPU (NVIDIA RTX 3080): 约30-45分钟
- GPU (NVIDIA GTX 1080): 约1-1.5小时
- CPU: 约3-5小时

训练完成后，模型会保存在 `models/` 目录，文件名类似：
```
ecg_quality_model_20260103_145230.h5
```

### 第5步：评估模型（约5-10分钟）

```bash
# 评估测试集（来自训练数据库）
python evaluate.py \
    --model models/ecg_quality_model_XXXXXX.h5 \
    --test_data processed_data/test_data.npz \
    --dataset_name "测试集"

# 评估未见数据 - PCCC2011
python evaluate.py \
    --model models/ecg_quality_model_XXXXXX.h5 \
    --test_data processed_data/pccc2011_test_data.npz \
    --dataset_name "PCCC2011"

# 评估未见数据 - INCART
python evaluate.py \
    --model models/ecg_quality_model_XXXXXX.h5 \
    --test_data processed_data/incart_test_data.npz \
    --dataset_name "INCART"
```

记得将 `XXXXXX` 替换为实际的时间戳！

评估结果会保存在 `results/` 目录，包括：
- 混淆矩阵图
- ROC曲线图
- 分类报告

## 🎉 使用训练好的模型

### 命令行使用

```bash
# 查看使用说明
python main.py --help

# 查看完整流程
python main.py --pipeline

# 运行演示
python main.py --demo --model models/ecg_quality_model_XXXXXX.h5

# 评估ECG文件
python main.py --assess \
    --model models/ecg_quality_model_XXXXXX.h5 \
    --input data/mitdb/100 \
    --format wfdb \
    --output results/assessment_result.json
```

### Python代码使用

```python
from main import ECGQualityAssessment
import numpy as np

# 加载模型
model_path = 'models/ecg_quality_model_XXXXXX.h5'
system = ECGQualityAssessment(model_path)

# 评估单个信号
ecg_signal = np.loadtxt('your_ecg_signal.txt')
sampling_rate = 360  # Hz

quality, confidence = system.assess_signal(ecg_signal, sampling_rate)
print(f"信号质量: {quality}")
print(f"置信度: {confidence:.2%}")

# 评估信号片段
results = system.assess_signal_segments(ecg_signal, sampling_rate)
for r in results:
    print(f"片段 {r['segment_index']}: {r['quality']} "
          f"(置信度: {r['confidence']:.2%})")
```

## 🔧 常见问题

### Q1: 下载数据集速度很慢怎么办？
A: 可以尝试：
1. 使用代理或VPN
2. 手动从PhysioNet下载
3. 询问同事是否已有数据集副本

### Q2: 训练时内存不足怎么办？
A: 可以：
1. 在 `prepare_data.py` 中减少 `max_segments`
2. 在 `train.py` 中减小批大小
3. 关闭数据增强（在 `prepare_data.py` 中设置 `use_augmentation=False`）

### Q3: 训练速度太慢怎么办？
A: 可以：
1. 使用GPU（强烈推荐）
2. 减少训练轮数（在 `config.py` 中调整 `epochs`）
3. 减少训练数据量

### Q4: 评估结果与论文差异较大怎么办？
A: 可能的原因：
1. 数据预处理细节差异
2. 训练数据划分不同
3. 模型初始化随机性
4. 测试数据标注方式不同

建议：
- 检查配置参数是否与论文一致
- 尝试多次训练取平均
- 调整超参数

### Q5: 如何调整模型参数？
A: 编辑 `config.py` 文件：
```python
MODEL_CONFIG = {
    'conv_filters': [8, 16, 32, 64],  # 调整滤波器数量
    'dropout_rate': 0.3,               # 调整dropout率
    # ...
}

TRAINING_CONFIG = {
    'batch_size': 10,     # 调整批大小
    'epochs': 100,        # 调整训练轮数
    'learning_rate': 0.001,  # 调整学习率
}
```
