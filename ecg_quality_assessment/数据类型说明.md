## 📊 数据流程对比

### 1️⃣ INCART数据库（使用SQI标注）

#### **输入数据**
```python

incart_records = loaders['incart'].load_all_records()
incart_segments = []  # list

for record_name, (signals, fs) in incart_records.items():
    for lead_idx in range(signals.shape[1]):
        lead_signal = signals[:, lead_idx]
        segments = preprocess_and_segment(lead_signal, fs, return_derivative=False)
        incart_segments.extend(segments)  # list of arrays
```

**类型**: `list` (包含多个numpy数组，每个形状为 `(1800,)`)

#### **SQI处理**
```python
X_incart = np.array(incart_segments)  # 转换为numpy数组
# X_incart.shape = (n_segments, 1800)
# X_incart.dtype = float64

y_incart, sqi_results = auto_label_incart_quality(X_incart, fs=360)
# y_incart.shape = (n_segments,)
# y_incart.dtype = int64 (值为0或1)
```

#### **输出数据**
```python
test_data['incart'] = (X_incart, y_incart)
# X_incart: numpy.ndarray, shape=(n_segments, 1800), dtype=float64
# y_incart: numpy.ndarray, shape=(n_segments,), dtype=int64
```

## 🎯 关键点

### ✅ **完全一致**

1. **数据结构相同**:
   ```python
   test_data = {
       'incart': (X_incart, y_incart),      # (numpy.ndarray, numpy.ndarray)
       'pccc2011': (X_pccc, y_pccc)         # (numpy.ndarray, numpy.ndarray)
   }
   ```

2. **后续处理无需修改**:
   - 训练脚本 `train.py` 无需修改
   - 评估脚本 `evaluate.py` 无需修改
   - 所有下游代码都能正常工作

3. **标签含义相同**:
   - `0` = 可接受/干净信号
   - `1` = 不可接受/含噪信号

---

## 🔬 唯一的区别

| 方面 | INCART (SQI) | PCCC2011 (真实标注) |
|------|--------------|---------------------|
| **标注方式** | 自动（基于SQI算法） | 真实（从标注文件读取） |
| **标注依据** | 8种信号质量指标 | 人工或官方标注 |
| **可调整性** | ✅ 可调整阈值 | ❌ 固定标注 |
| **额外信息** | 返回详细SQI结果 | 仅返回标签 |

**但是**，这些区别只影响**如何生成标签**，不影响**数据格式**。

## 🎉 总结

### **答案：是的，完全一样！**

✅ SQI处理后的数据与之前加载的数据类型**完全一致**  
✅ 都是 `(numpy.ndarray, numpy.ndarray)` 元组  
✅ 信号数据 X: `shape=(n_segments, 1800), dtype=float64`  
✅ 标签数据 y: `shape=(n_segments,), dtype=int64, values={0, 1}`  
✅ 无需修改任何下游代码  

**唯一的区别**是标签的**生成方式**：
- INCART: 基于SQI算法自动生成
- PCCC2011: 从真实标注文件读取

但最终的**数据格式和结构完全相同**，可以无缝对接训练和评估流程。
