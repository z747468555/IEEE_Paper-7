## 🚀 推荐的学习路径

### 初学者路径

1. **阅读文档**（30分钟）
   - 阅读 `快速入门指南.md`
   - 了解项目结构和流程

2. **测试环境**（5分钟）
   ```bash
   python test_installation.py
   ```

3. **准备少量数据**（10分钟）
   - 编辑 `prepare_data.py`
   - 设置 `max_segments = 500`（减少数据量）
   - 运行 `python prepare_data.py`

4. **快速训练**（10分钟）
   - 编辑 `config.py`
   - 设置 `epochs = 10`（减少训练轮数）
   - 运行 `python train.py`

5. **评估模型**（5分钟）
   ```bash
   python evaluate.py --model models/ecg_quality_model_*.h5 \
       --test_data processed_data/test_data.npz
   ```

### 高级用户路径

1. **完整数据准备**（20分钟）
   ```bash
   python prepare_data.py
   ```

2. **完整训练**（1-2小时）
   ```bash
   python train.py
   ```

3. **全面评估**（15分钟）
   ```bash
   # 评估所有测试集
   python evaluate.py --model models/best_model.h5 \
       --test_data processed_data/test_data.npz
   python evaluate.py --model models/best_model.h5 \
       --test_data processed_data/incart_test_data.npz
   ```

4. **参数调优**
   - 修改 `config.py` 中的参数
   - 重新训练和评估
   - 比较结果

5. **应用部署**
   - 使用 Python API
   - 创建 Web 服务
   - 集成到应用中
