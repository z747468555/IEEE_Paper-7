📌 项目目标
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
复现论文《Automatic ECG signal quality assessment using convolutional neural 
networks and derivative ECG signal for false alarm reduction in wearable vital 
signs monitoring devices》的实验，实现一个完整的ECG信号质量评估系统。

🧠 模型架构详解
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

输入层：
  └─ dECG信号 (1799, 1)

卷积块 1：
  ├─ Conv1D (8滤波器, 6×1核)
  ├─ ELU激活
  ├─ MaxPooling (3×1, stride=2)
  └─ Dropout (0.3)

卷积块 2：
  ├─ Conv1D (16滤波器, 6×1核)
  ├─ ELU激活
  ├─ MaxPooling (3×1, stride=2)
  └─ Dropout (0.3)

卷积块 3：
  ├─ Conv1D (32滤波器, 6×1核)
  ├─ ELU激活
  ├─ MaxPooling (3×1, stride=2)
  └─ Dropout (0.3)

卷积块 4：
  ├─ Conv1D (64滤波器, 6×1核)
  ├─ ELU激活
  ├─ MaxPooling (3×1, stride=2)
  └─ Dropout (0.3)

全连接层：
  ├─ Flatten
  ├─ Dense (32) + ELU + Dropout
  ├─ Dense (16) + ELU + Dropout
  ├─ Dense (8) + ELU + Dropout
  └─ Dense (1) + Sigmoid

输出：
  └─ 质量预测 (0=干净, 1=含噪)

模型大小：~2,989 KB
参数数量：~30,000


🔍 关键技术点
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 导数特征 (dECG)
   ─────────────────
   • 增强信号变化特征
   • 减少基线漂移影响
   • 公式: d[n] = y[n+1] - y[n]

2. 双向滤波
   ─────────────────
   • 高通：0.8Hz切比雪夫滤波器（去基线漂移）
   • 低通：40Hz切比雪夫滤波器（去高频噪声）
   • 零相位失真

3. 噪声生成
   ─────────────────
   • 3种噪声：基线漂移、肌电干扰、电极移动
   • 3种衰减因子：0.3, 0.6, 0.9
   • 公式: NECG = 干净信号 + a × 噪声

4. 数据增强
   ─────────────────
   • 微小随机噪声：衰减因子0.001-0.004
   • 增加训练样本多样性

5. 轻量级架构
   ─────────────────
   • 仅~30k参数
   • 适合嵌入式部署
   • 快速推理


📖 使用示例
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【命令行使用】

# 查看帮助
python main.py --help

# 查看完整流程
python main.py --pipeline

# 运行演示
python main.py --demo --model models/ecg_quality_model_*.h5

# 评估ECG文件
python main.py --assess \
    --model models/ecg_quality_model_*.h5 \
    --input data/mitdb/100 \
    --format wfdb


【Python代码使用】

from main import ECGQualityAssessment
import numpy as np

# 初始化系统
model_path = 'models/ecg_quality_model_20260103.h5'
system = ECGQualityAssessment(model_path)

# 评估信号
ecg_signal = np.loadtxt('signal.txt')
quality, confidence = system.assess_signal(ecg_signal, 360)
print(f"质量: {quality}, 置信度: {confidence:.2%}")


⚙️ 配置参数
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

所有参数都在 config.py 中定义，主要包括：

数据参数：
  • TARGET_SAMPLING_RATE = 360        # 目标采样率
  • SEGMENT_DURATION = 5              # 片段长度（秒）

滤波器参数：
  • HIGHPASS_CUTOFF = 0.8             # 高通截止频率
  • LOWPASS_CUTOFF = 40               # 低通截止频率

模型参数：
  • conv_filters = [8, 16, 32, 64]    # 卷积滤波器
  • kernel_size = 6                   # 卷积核大小
  • dropout_rate = 0.3                # Dropout率

训练参数：
  • batch_size = 10                   # 批大小
  • epochs = 100                      # 训练轮数
  • learning_rate = 0.001             # 学习率


❓ 常见问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: 数据下载失败？
A: 尝试手动从PhysioNet下载或使用VPN

Q: 内存不足？
A: 减少max_segments或关闭数据增强

Q: 训练太慢？
A: 使用GPU或减少训练轮数

Q: 结果与论文不符？
A: 正常现象，可能因数据划分、随机初始化等因素

Q: 如何调整参数？
A: 编辑config.py文件
